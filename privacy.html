Конфиденциальность

Обновлено 19 октября 2026 года

Keep Keep — личный проект для семейного бюджета двух пользователей. Приложение находится в разработке. Эта страница описывает доступ к Google и хранение данных при подключении источника.

Какие данные используются

После согласия владельца сервис получает OAuth credentials для Google Drive, адрес аккаунта владельца и доступ к используемым приложением файлам. Запрашивается scope drive.file: файлы, созданные приложением или выбранные владельцем для работы с ним.

Для чего нужен доступ

Доступ нужен для подключения источника бюджета, чтения планов и расходов и передачи расходов, введённых пользователем. На этапе подготовки чтение и запись проверяются на отдельном синтетическом файле. Реальный бюджет подключается отдельно владельцем.

При первоначальной настройке публичного сайта владелец отдельно разрешает проверку владения сайтом через Google. Эта авторизация хранится на Mac и используется только для подтверждения сайта; бюджетный сервер её не получает.

Где хранятся данные

Бюджет остаётся в выбранном файле Google Drive. Credentials подключения хранятся в закрытом каталоге личного сервера в Германии. При первоначальной настройке приватная копия credentials также сохраняется на Mac владельца. Секреты и реальные финансовые данные не публикуются в репозитории проекта.

Передача данных к Google и серверу выполняется по HTTPS. Сервису нужен доступ к содержимому выбранного файла для расчёта бюджета; это не сквозное шифрование от сервера.

Передача третьим лицам

Google-данные используются для работы с семейным бюджетом. Они не продаются и не используются для рекламы. Использование данных Google ограничено описанными здесь функциями и Google API Services User Data Policy, включая Limited Use.

Отзыв доступа и удаление

Владелец может отозвать доступ Keep Keep в подключениях своего Google-аккаунта. После отзыва сервис не сможет обновлять доступ к Drive. Уже сохранённые credentials и локальные копии удаляются владельцем проекта с Mac и сервера. Отзыв доступа сам по себе не удаляет исходную книгу из Google Drive.

Эти страницы и поддержка

Информационные страницы размещены на GitHub Pages. GitHub обрабатывает технические сведения о посещениях по своей политике конфиденциальности. На страницах нет собственной аналитики и рекламных скриптов.

Вопросы о проекте и удалении данных можно адресовать автору проекта или через support email, указанный на экране доступа Google.
